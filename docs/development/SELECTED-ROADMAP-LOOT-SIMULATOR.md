# GAME-04 first slice
Deterministic bounded simulation of the supported crate model, with weighted set and entry selection, without-replacement rules, uniform counts/quantity, blueprint chance and forced blueprints. Aggregates appearances per opening, total quantity and blueprint quantity. Explicitly reports shortfalls and append-to-vanilla incompleteness. No file writes and no claim to reproduce ASA RNG, stat quality or vanilla loot. Reference: YARK supply-crate-simulator.ts; independent PRNG and implementation. Tests verify deterministic results, fixed grants, weights, bounds and unknown vanilla content.
