# RCON-01/02: closed idle socket detection and console history
Reuse owned persistent read sessions and reconnect an observably closed idle TCP socket before a new dispatch. Existing exact PID/epoch/port/credential checks and one-shot mutation path remain intact. Add map-local bounded history of verified console receipts and selectable read-only favorites for fresh and historical consoles. Store only fixed action identifiers/time/status in the local WebView profile, not arguments, replies or credentials. No audit claim across all native dispatchers, no auto replay. Native durable audit and custom argument storage are not implemented.
