# GAME-03 first slice
Structured local Game.ini loot draft editor inspired by YARK supply-crate-entries.ts. Independently implements a strict, bounded subset of ASA crate/set/entry fields: explicit uniform power, single class per entry, positive weights, counts, quantities, qualities and blueprint chance. Supports multiple sets and entries. Unsupported original rows remain unchanged; ambiguity blocks structured edit rather than rewriting unknown fields. Native existing stopped-map ETag preview and save remain the sole file write. Broader parser, multiple class choices, deletion, live runtime acceptance remain pending.
