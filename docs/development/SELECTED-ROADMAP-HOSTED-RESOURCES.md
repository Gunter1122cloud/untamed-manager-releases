## Durable local profile (follow-up)
Normal Manager profiles persist explicitly published text encrypted using SecureStore, with atomic same-directory replacement. Startup restores the same loopback port; failed restoration is visible, never replaces the saved data implicitly. Explicit stop removes the persisted state; process disposal alone preserves it. Smoke/manual acceptance profiles remain ephemeral. Tests exercise a real HTTP restart and encrypted storage. No ASA configuration changes or public network access.
