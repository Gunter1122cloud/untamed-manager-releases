# Direct mod video collection — Chapter III
The primary target is real, distinct motion footage, not slides. This branch-only workflow scans official mod pages for public direct media and the Runic Wyverns creator's public Bluesky media posts. It records source URLs, native resolution, FPS, duration, SHA256, and whether a clip was obtained. Reference clips are temporary artifacts, not a public redistribution license. No authentication bypass. 50 MB maximum for the new batch. Prior source pack limits remain in effect.
